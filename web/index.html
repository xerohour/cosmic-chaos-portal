Architecture

This page is a self-contained port of the Cosmic Chaos Portal core (src/ccp/). One Archon orchestrator owns the state machine; six specialist agents run beneath it and never coordinate with each other or publish directly.

  1. Validate — the intention is checked before anything runs.
  2. Safety gate — crisis language short-circuits to human-support resources; substance facilitation and neural-device guidance are blocked outright.
  3. Plan — life-area tags map to specialists, intersected with your consent. The Integration agent is always anchored.
  4. Divine — specialists run in parallel under a time budget; every one is deterministic.
  5. Aggregate — each result passes a content check; violating results are dropped.
  6. Synthesize — themes are deduped and confidence-ranked with provenance; spiritual or plain voice follows your consent.
  7. Safety review — the final gate strips medical claims, substance mentions, and certainty language, and attaches the uncertainty frame.
